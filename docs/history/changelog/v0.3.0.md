# YunmengZe Agent v0.3.0

**Alpha · Pre-release**  
**Alpha · 预发布**

TUI session leave + copyable transcript: `/new` returns to ready (and cancels a running turn), the frame has breathing room, and drag-select copy works because mouse cell motion and bubblezone are gone.

TUI 离会话 + 可划选复制：`/new` 回到 ready（运行中则取消本轮），聊天列有边距，去掉 mouse cell motion 与 bubblezone 后可划选复制。

## Highlights / 亮点

| Area | Change |
| --- | --- |
| **`/new`** | Leaves the current session (ready page). Does not take a message — type on ready to start. Cancels a running turn. Cancel or GetTask failure still leaves (GetTask failure does not cancel). |
| **Unfocused TUI** | Drops model streams, in-flight refresh, and permission SSE/poll. Pending-permission chrome is cleared (daemon queue unchanged). |
| **Frame** | Padding 1 row / 2 cols + module gaps. Narrow terminals no longer inflate the frame or chat viewport. Header/footer truncate stays a single line with an ellipsis. |
| **Copy** | Drop `WithMouseCellMotion` and `bubblezone`. Fold/expand is keyboard-only (`e` / `E` / `c`). Transcript drag-select copies clean text. |

### 中文摘要

| 区域 | 变更 |
| --- | --- |
| **`/new`** | 离焦 ready；不带消息；运行中 cancel；失败仍离焦 |
| **无焦点** | 丢掉旧 stream / refresh / permission SSE |
| **边距** | 窄屏不再撑宽；单行省略 |
| **划选** | 去掉 bubblezone；折叠仅键盘 |

## Install / 安装

**Recommended:**

```bash
brew install --cask yyZe0122/tap/ymz
# or upgrade: brew upgrade --cask ymz
ymz version && ymzd --check
```

```powershell
scoop bucket add ymz https://github.com/yyZe0122/scoop-bucket
scoop install ymz
# or: scoop update ymz
```

**Fallback:**

```powershell
$env:YMZ_VERSION = 'v0.3.0'
irm "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install.ps1" | iex
```

```bash
export YMZ_VERSION=v0.3.0
curl -fsSL "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install-user.sh" | sh
```

Config root: **`~/.yunmengze`** · `ymz paths user` · `ymz config validate --mode user`.

## Notes

- TUI: `/quit` then `ymz tui` (or `ymz restart`) so the new binary loads.
- `/new` no longer starts a session with a message. Type on the ready page.
- Fold/expand is `e` / `E` / `c` only — click-to-expand is gone so the terminal can drag-select.
- Affiliate repos: `yyZe0122/homebrew-tap` (`Casks/ymz.rb`), `yyZe0122/scoop-bucket`.
