# YunmengZe Agent v0.2.8

**Alpha · Pre-release**  
**Alpha · 预发布**

Phase Q coding loop: one `ContextView` after model pin, stronger file/shell tools, session todos, human rewind, plus Q-harden so long sessions keep recent turns and the model is steered to use tools.

Phase Q 编码循环：模型 pin 之后一次 `ContextView` 装配、加强文件/shell 工具、会话 todo、人径 rewind；Q-harden 让长会话保住近轮，并引导模型走工具。

## Highlights / 亮点

| Area | Change |
| --- | --- |
| **ContextView (QA/QB)** | Single `ContextView.Build` after job/session/main pin. Prefix + Summary + Tail + Ephemeral. `RunRequest.History` retired. Packing uses `SessionTranscriptTail`. |
| **Q-harden** | Hot-path `packForProvider` is L1-only. Missing `through_message_id` in the tail window keeps the whole tail. New compaction rows write the real model id. Mid-turn rebuild keeps todos in Ephemeral. `HistoryBudget` never exceeds usable. |
| **Files (QC)** | `fs_read` line window + sha256. `fs_patch`/`fs_write` CRLF/indent/hash/diff. `fs_glob` `**`. |
| **Shell (QD)** | `process_shell` (`/bin/sh -c`) shares `chat.tools.process` with `process_exec`. Plan/cron never granted. Default still off. |
| **Todos (QE)** | `session_todos` + `todo_list`/`todo_write` (R0). Compact list in Ephemeral, never Prefix. |
| **Search (QF)** | `AppendToolResult` projects tool name+path into `transcript_search`. |
| **Rewind (QG/QH)** | `edit_revisions` + `POST /v1/sessions/{id}/rewind`. Esc cancels the turn; Esc Esc / `/undo` restores the last file edit. |
| **Prompt** | Short coding-loop system prompt: no invented files, read then patch, parallel reads, todos, `session_search` after compact. |

## Install / 安装

**Recommended:**

```bash
brew install --cask yyZe0122/tap/ymz
# or upgrade: brew upgrade --cask ymz
ymz version && ymzd --check
```

```powershell
scoop bucket add ymz https://github.com/yyZe0122/scoop-bucket
scoop install ymz
# or: scoop update ymz
```

**Fallback:**

```powershell
$env:YMZ_VERSION = 'v0.2.8'
irm "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install.ps1" | iex
```

```bash
export YMZ_VERSION=v0.2.8
curl -fsSL "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install-user.sh" | sh
```

Config root: **`~/.yunmengze`** · `ymz paths user` · `ymz config validate --mode user`.

## Notes
