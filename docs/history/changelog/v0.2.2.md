# YunmengZe Agent v0.2.2

**Alpha · Pre-release**  
**Alpha · 预发布**

Provider **hot-reload**, multi-provider catalog UX, daemon short commands, and clearer model `ready` errors.

主 provider 配置热更新、多供应商目录体验、daemon 短命令，以及更明确的 model `ready` 错误提示。

## Highlights / 亮点

| Area | Change |
| --- | --- |
| **Hot-reload** | Edits to `agent.json` / `agent.local.json` / `env` rebuild the **main** provider stack (~0.5s). See [ADR-048](../architecture/048-provider-config-hot-reload.md). |
| **Keys** | Literal / `{file:}` API keys and empty-process `{env:VAR}` from `env` file reload live (fingerprint hashes secrets; process env still wins when already set). |
| **Not reloaded** | `chat.*`, MCP, role map `models.subagent\|compact` → `ymz restart`. Daemon started without agent → fix config then **restart** (no late-bind). |
| **Catalog** | Nested `provider.<id>.models` with **bare** model ids; same bare id on two suppliers OK (`a/m` vs `b/m`). Mistyped `provider/model` catalog keys accepted as convenience. |
| **CLI** | `ymz start\|stop\|restart\|status` (+ long form `ymz daemon …` including `restart`). |
| **API / TUI** | `GET/PUT /v1/config/model` exposes `ready` + secret-free `error`; TUI `/model` surfaces load failures instead of a silent “switch unavailable”. |
| **Packages** | `internal/providerruntime` (load / switch / reload), `internal/configreload` (fsnotify debounce). |

## Install / 安装

**Recommended:**

```bash
brew install --cask yyZe0122/tap/ymz
# or upgrade: brew upgrade --cask ymz
ymz version && ymzd --check
```

```powershell
scoop bucket add ymz https://github.com/yyZe0122/scoop-bucket
scoop install ymz
# or: scoop update ymz
```

**Fallback:**

```powershell
$env:YMZ_VERSION = 'v0.2.2'
irm "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install.ps1" | iex
```

```bash
export YMZ_VERSION=v0.2.2
curl -fsSL "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install-user.sh" | sh
```

Config root: **`~/.yunmengze`** · `ymz paths user` · `ymz config validate --mode user`.

## Notes

- In-flight chat turns keep the previous provider client until the next turn.
- `ready: false` with a restart message means chat was never wired at daemon start — validate config then `ymz restart`.
- Affiliate repos: `yyZe0122/homebrew-tap` (`Casks/ymz.rb`), `yyZe0122/scoop-bucket`.
