# YunmengZe Agent v0.2.7

**Alpha · Pre-release**  
**Alpha · 预发布**

T8 tighten: streaming replies freeze a glamour'd prefix at the last safe blank line; the growing trail stays plain. Paint coalesces at 32ms. Stream state lives on the TUI model, not a package global.

T8 收紧：流式回复在最后一个安全空行冻结 glamour 前缀；增长中的 trail 永远原文。32ms 合帧。流状态挂在 TUI `model` 上，不再用包级可变会话状态。

## Highlights / 亮点

| Area | Change |
| --- | --- |
| **Live markdown (T8)** | Glamour only the frozen prefix (`safeMarkdownCut` = blank line + no open fence). Trail is always plain. No per-token glamour; no list/quote/table heuristics. |
| **Paint** | SSE deltas mark dirty; `tea.Tick(32ms)` rebuilds the live timeline row once. Tool-call lines still paint immediately. |
| **State** | `streamingMD` on `model`, passed via `renderOpts.Stream`. `resetLiveStream` on complete, authoritative transcript, and `clearTask`. |
| **Draft** | `upsertLiveDraft` replaces the tail `live` row (no caret flicker). |

### 中文摘要

| 区域 | 变更 |
| --- | --- |
| **T8** | 冻结前缀 glamour；trail 永远 plain；未闭合围栏不切 |
| **合帧** | 32ms 重绘 live 行，不再每个 delta 重建 timeline |
| **状态** | `streamingMD` 进 model；complete / refresh / clear 同一条复位 |

## Install / 安装

**Recommended:**

```bash
brew install --cask yyZe0122/tap/ymz
# or upgrade: brew upgrade --cask ymz
ymz version && ymzd --check
```

```powershell
scoop bucket add ymz https://github.com/yyZe0122/scoop-bucket
scoop install ymz
# or: scoop update ymz
```

**Fallback:**

```powershell
$env:YMZ_VERSION = 'v0.2.7'
irm "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install.ps1" | iex
```

```bash
export YMZ_VERSION=v0.2.7
curl -fsSL "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install-user.sh" | sh
```

Config root: **`~/.yunmengze`** · `ymz paths user` · `ymz config validate --mode user`.
