# YunmengZe v0.1.2

**Alpha · Pre-release**  
**Alpha · 预发布**

Package-manager distribution: Homebrew Cask + Scoop, updated automatically on release.

分发渠道：Homebrew Cask + Scoop，发版时由 GoReleaser 自动更新。

## Highlights / 亮点

- **Homebrew** (`yyZe0122/homebrew-tap`): `brew install --cask yyZe0122/tap/ymz`
- **Scoop** (`yyZe0122/scoop-bucket`): `scoop bucket add ymz https://github.com/yyZe0122/scoop-bucket` then `scoop install ymz`
- One-line install scripts remain as **fallback** (not primary).
- 一键安装脚本降为**兜底**；主推包管理器。

## Install / 安装

**Recommended:**

```bash
brew install --cask yyZe0122/tap/ymz
scoop bucket add ymz https://github.com/yyZe0122/scoop-bucket
scoop install ymz
Fallback:
$env:YMZ_VERSION = 'v0.1.2'
irm "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install.ps1" | iex
export YMZ_VERSION=v0.1.2
curl -fsSL "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install-user.sh" | sh
Then set a key (any one method) and run ymz.
Notes
- First release that publishes Homebrew Cask + Scoop manifests.
- Affiliate repos: yyZe0122/homebrew-tap (Casks/ymz.rb), yyZe0122/scoop-bucket (agent.json).
