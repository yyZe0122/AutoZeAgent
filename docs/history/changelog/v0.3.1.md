# YunmengZe Agent v0.3.1

**Alpha · Pre-release**  
**Alpha · 预发布**

Coding-loop harness (fail-as-observation, turn/step/steer, `ask_user`) plus Tab **plan → agent → auto**, and a product README (TUI-first; stale architecture SVG gone).

编码循环 harness（失败是观察、turn/step/steer、`ask_user`）+ Tab **plan → agent → auto**，以及产品向 README（TUI 为主；去掉过时架构图）。

## Highlights / 亮点

| Area | Change |
| --- | --- |
| **Harness R1** | Tool business failures and process/git non-zero exits feed back as tool JSON; the turn continues. `AllowedTools` unique by name (default TUI Agent no longer dies on duplicate advertise). [ADR-052](../../wiki/adr/052-coding-loop-harness.md). |
| **Harness R2** | Step loop + process-local next-step inbox. `chat.max_iterations` omit/0 = no hard cap (1–256 soft-lands). |
| **Harness R3** | `POST /v1/sessions/{id}/steer`. TUI Enter during a running turn queues next-step text (does not cancel tools). |
| **Harness R4** | `ask_user` + `user_questions` + `GET/POST /v1/questions`. TUI question card (`/perm` wins). CLI/cron returns unavailable. |
| **Harness R5** | Skill catalog (id — one line) in Prefix. `http_get` in interactive agent (ask + host-narrowed similar); plan/cron never advertise it. Sub-agents inherit AGENTS.md. |
| **Tab stance** | Tab cycles **plan → agent → auto**. Kernel `execution_mode` stays agent\|plan. Auto = session `permission_stance` (this session pre-grants process+git). Interactive Agent waits `/perm`. CLI/`ymz run` fail-closed. |
| **Prefix** | Short identity (`YunmengZe Agent <version>`, roles, no vision) plus pin-after `<env>` (model / workspace / UTC date). User `AGENTS.md` stays a separate overlay. |
| **TUI** | Header and `/status` show daemon version. Live replies stay unfolded; mid-turn refresh keeps the typewriter; viewport pins to bottom. |
| **README** | Product page: coding loop + TUI first. [English](../../../README.md) · [简体中文](../../../README.zh.md). Stale `docs/assets/architecture.svg` removed. |

## Install / 安装

**Recommended:**

```bash
brew install --cask yyZe0122/tap/ymz
# or upgrade: brew upgrade --cask ymz
ymz version && ymzd --check
```

```powershell
scoop bucket add ymz https://github.com/yyZe0122/scoop-bucket
scoop install ymz
# or: scoop update ymz
```

**Fallback:**

```powershell
$env:YMZ_VERSION = 'v0.3.1'
irm "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install.ps1" | iex
```

```bash
export YMZ_VERSION=v0.3.1
curl -fsSL "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install-user.sh" | sh
```

Config root: **`~/.yunmengze`** · `ymz paths user` · `ymz config validate --mode user`.

## Notes

- TUI: `/quit` then `ymz tui` (or `ymz restart`) so the new binary loads.
- While a turn is running, Enter **steers**; Esc or `/new` cancels.
- Tab Auto pre-grants process+git for **this session only**.
- Affiliate repos: `yyZe0122/homebrew-tap` (`Casks/ymz.rb`), `yyZe0122/scoop-bucket`.
