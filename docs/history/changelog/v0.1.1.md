# YunmengZe v0.1.1

**Alpha · Pre-release**  
**Alpha · 预发布**

Installer and config UX release on top of v0.1.0.

在 v0.1.0 之上：一键安装体验与配置/密钥写法补强。

## Highlights / 亮点

- **User installers** (Windows / Linux / macOS): install three binaries only, persist **PATH**, seed **ConfigDir** `agent.json` + optional **`env`** file (never overwrite existing).
- **一键安装**：只装三个二进制、持久化 PATH、种子配置与 `env`（不覆盖已有文件）。
- **Runtime loads ConfigDir `env`** before resolving `{env:…}` (does not override process env already set).
- **运行时加载** ConfigDir `env`（不覆盖已有进程环境变量）。
- **API key options (none forced):** `{env:VAR}`, `{file:…}`, or **literal** `apiKey` in JSON — documented in README / provider-protocols / example config.
- **密钥三种写法（均不强制）**：环境变量、文件引用、JSON 明文。
- Example config documents env / file / literal side by side.
- 示例配置并列展示三种 apiKey 写法。

## Install / 安装

```powershell
$env:YMZ_VERSION = 'v0.1.1'
irm "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install.ps1" | iex
```

```bash
export YMZ_VERSION=v0.1.1
curl -fsSL "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install-user.sh" | sh
```

Then set a key (any one method) and run `ymz`.

## Notes

- Rebuild required vs v0.1.0 for **env file load** in the daemon/CLI binaries.
- One-line install scripts are served from `main` raw; pin `YMZ_VERSION` to this tag for matching binaries.
