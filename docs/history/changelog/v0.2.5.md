# YunmengZe Agent v0.2.5

**Alpha · Pre-release**  
**Alpha · 预发布**

Hermes-style skill list/view, in-process skill drafts and unused archive (ADR-050), `AGENTS.md` rules, memory `default_ttl` soft-archive, habit hints, tighter injectscan, and throttled live markdown.

Hermes 式 skill 按需加载、进程内草稿与未用归档（ADR-050）、`AGENTS.md` 规则、记忆 `default_ttl` 软归档、习惯提示、收紧 injectscan、节流 live markdown。

## Highlights / 亮点

| Area | Change |
| --- | --- |
| **Skill list/view** | Model loads via `skills_list` → `skill_view` (optional `file_path`). `/skills` and job `skill_ids` still explicit snapshot preload. Keyword auto-inject removed. |
| **Skill drafts (H3)** | Agent `skill_draft` writes `SKILL.md.draft`. Human `/skills apply\|reject <id>`; apply backups first. System source immutable. |
| **Skill archive (H5)** | Submit / `skill_view` records `last_used`. `chat.skills.unused_ttl` soft-archives (never-used skipped). `GET /v1/skills?include_archived=` · `/skills archived`. Archive writes `skill_events`. |
| **Journey** | `/journey` / `/journey skills` prepends `skill_events` (C4). |
| **AGENTS.md** | `EnsureConfig` seeds ConfigDir rules. Global always injected; workspace `.yunmengze/AGENTS.md` appended. `injectscan`; no grants. |
| **Memory (H5-lite)** | `chat.memory.default_ttl` on session/detail writes; expire via `archived_at` (startup + after turn). `/memory archived`. |
| **Habit hints (H4)** | Pending permission `suggested_decision` / `suggested_reason` (once/similar). Same session; directory-prefix paths; never auto-decide / never permanent. |
| **injectscan (H6)** | More zero-width / bidi / jailbreak markers; drafts scanned the same way. |
| **Live markdown (T8)** | Streaming replies use throttled glamour (per-block cache). Unclosed fences stay plain. |
| **MCP prefer** | MCP tools listed before `process_exec`; prompt/description prefer configured `mcp_*`. |

## Install / 安装

**Recommended:**

```bash
brew install --cask yyZe0122/tap/ymz
# or upgrade: brew upgrade --cask ymz
ymz version && ymzd --check
```

```powershell
scoop bucket add ymz https://github.com/yyZe0122/scoop-bucket
scoop install ymz
# or: scoop update ymz
```

**Fallback:**

```powershell
$env:YMZ_VERSION = 'v0.2.5'
irm "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install.ps1" | iex
```

```bash
export YMZ_VERSION=v0.2.5
curl -fsSL "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install-user.sh" | sh
```

Config root: **`~/.yunmengze`** · `ymz paths user` · `ymz config validate --mode user`.

## Notes

- TUI: exit old process after upgrade (`/quit` then `ymz tui`) so the new binary loads.
- Existing `~/.yunmengze/AGENTS.md` is not overwritten; only missing files are seeded.
- Skill drafts never expand grants. Apply is human-only.
- Habit hints are read-only; `/perm` still decides.
- Affiliate repos: `yyZe0122/homebrew-tap` (`Casks/ymz.rb`), `yyZe0122/scoop-bucket`.
- Design: `docs/optimization/current.md` · ADRs 034/036/043/044/050.
