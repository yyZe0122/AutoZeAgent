# YunmengZe Agent v0.2.6

**Alpha · Pre-release**  
**Alpha · 预发布**

TUI visual pass: marsh palette (云梦泽 / 楚地烟波), flattened chat chrome, three-column wide layout. Also ships the post-v0.2.5 docs box split and leftover planner cleanup.

TUI 视觉改版：泽夜/泽昼色盘、去套娃平铺对话、宽屏三栏。一并带上 v0.2.5 之后的文档三盒与 Planner 残留清理。

## Highlights / 亮点

| Area | Change |
| --- | --- |
| **TUI layout** | Wide (≥120): session rail · chat · context. Drop nested viewport/input rounded cages. `/help` floats; no longer replaces the transcript. |
| **Messages** | User = left accent bar; assistant = full-bleed markdown; thinking/tool = one line (no empty boxes). Done = one 青碧 rule, not `════`. |
| **Palette** | Night 泽夜 / day 泽昼. Low-sat mist teal + moon-white; **朱砂** pulse while running; **青碧** done line. Keyword / slash / code = reed gold (`#F0D78A` night). |
| **Docs** | `docs/` three boxes: `wiki/` · `history/changelog/` · `backlog/current.md`. Publish notes path unchanged in spirit: `docs/history/changelog/vX.Y.Z.md`. |
| **Cleanup** | Removed leftover Planner approval CLI/DTO/states; systemd `planner.env` → `/etc/yunmengze/env`. Migrations 024–025. |

## Install / 安装

**Recommended:**

```bash
brew install --cask yyZe0122/tap/ymz
# or upgrade: brew upgrade --cask ymz
ymz version && ymzd --check
```

```powershell
scoop bucket add ymz https://github.com/yyZe0122/scoop-bucket
scoop install ymz
# or: scoop update ymz
```

**Fallback:**

```powershell
$env:YMZ_VERSION = 'v0.2.6'
irm "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install.ps1" | iex
```

```bash
export YMZ_VERSION=v0.2.6
curl -fsSL "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install-user.sh" | sh
```

Config root: **`~/.yunmengze`** · `ymz paths user` · `ymz config validate --mode user`.
