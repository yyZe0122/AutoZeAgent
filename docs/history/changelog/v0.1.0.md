# YunmengZe v0.1.0

**Alpha · first binary Pre-release**  
**Alpha · 首个二进制预发布**

Local-first, policy-controlled automation agent in Go: dual-track session chat, Tool Broker, and a single SQLite source of truth.

本地优先、受策略约束的 Go 自动化智能体：双轨会话对话、Tool Broker、单一 SQLite 事实源。

> Review config, policy, and permission boundaries before using important data or privileged credentials.  
> 在接触重要数据或高权限凭据前，请先检查配置与权限边界。

## Highlights / 亮点

- **Dual-track chat:** **agent** (build · read/write workspace tools) and **plan** (read-only analysis); no interactive Planner approval pipeline.
- **双轨会话：** **agent**（可写）与 **plan**（只读分析）；无独立 Planner 整单审批轨。
- **Tool Broker** is the only model-requested effect path (policy → grant → containment → limits → audit). Optional tool-call permission (`ask`: once / similar / permanent / deny).
- **Tool Broker** 为模型副作用唯一通道。可选 tool-call 权限（`ask`：once / similar / permanent / deny）。
- **In-process memory**, context packing/compaction, chat-native scheduled jobs (`/cron`), MCP via Broker.
- **进程内记忆**、上下文装配/压缩、chat 原生定时任务（`/cron`）、经 Broker 的 MCP。
- **TUI primary UX** (`ymz` / no-arg); CLI secondary. Structured logs (`ymz logs`).
- **TUI 为主路径**（`ymz`）；CLI 次要。结构化日志（`ymz logs`）。

## Install / 安装

Use the **one-line installer**: binaries on PATH, config + optional `env` file under the OS config dir. Release zip/tar is a portable bundle only.

一键安装：二进制进 PATH，配置与可选 `env` 写入系统配置目录。Release 压缩包仅为便携归档。

**API key（任选，不强制）：** ConfigDir `env` / 进程环境 + `{env:…}` · `{file:…}` · JSON 明文 `apiKey`。

**Pin this Pre-release** / **固定版本**：

```powershell
# Windows → bin under LocalAppData\Programs\YunmengZe\bin + user PATH
# config/env → %APPDATA%\YunmengZe\
$env:YMZ_VERSION = 'v0.1.0'
irm "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install.ps1" | iex
```

```bash
# Linux/macOS → ~/.local/bin + shell rc PATH
# config/env → ~/.config/yunmengze/
export YMZ_VERSION=v0.1.0
curl -fsSL "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install-user.sh" | sh
```

```bash
ymz version    # expect 0.1.0
ymz                    # TUI
```

Config lives only under the OS config directory (e.g. `~/.config/yunmengze/`). Prefer `{env:VAR}` for API keys. See README.

配置仅放在系统/用户配置目录；API Key 请用 `{env:…}`。详见 README。
