# YunmengZe Agent v0.2.4

**Alpha · Pre-release**  
**Alpha · 预发布**

Phase 1 OpenCode experience (import / remote MCP / slash commands / session prefer), job model pin (H7), memory curator (H1-lite), and a **bubble-style TUI** (Phase 2 polish).

Phase 1 OpenCode 体验（import / 远程 MCP / slash / 会话 prefer）、Job 模型钉死（H7）、记忆策展（H1-lite），以及 **气泡化 TUI**（Phase 2 抛光）。

## Highlights / 亮点

| Area | Change |
| --- | --- |
| **TUI bubbles** | Rounded lipgloss cards for user / assistant / thinking / tool; done banner; empty-session chips. Not a log dump. |
| **Fold / expand** | Thinking (live tail) + long tool results fold by default. `/expand [all\|none\|last]`; keys `e` / `E` / `c`; click via **bubblezone**. |
| **Markdown** | **glamour** for completed replies that look like markdown; streaming stays plain + prefix cache. |
| **Permission SSE** | Events `permission.pending` / `permission.decided` refresh the TUI `/perm` queue; decide still HTTP only (ADR-043). |
| **Journey** | `/journey` prepends read-only session memory rows (`ListMemory`). |
| **import-opencode** | `ymz config import-opencode` → `agent.local.json` (O1). |
| **MCP remote** | Streamable HTTP + legacy SSE (O2 / ADR-040). |
| **Slash** | skill-as-slash + `chat.commands` templates (O3). |
| **Session prefer** | `/model prefer` + run-level resolve prefer→main (O4); shared `modelresolve` with H7. |
| **Job model pin** | `jobs.model_ref` at create; empty/unresolvable pin → skip + fail ACK (H7). |
| **Memory curator** | H1-lite turn-end aux → `memory_entries`; freeze inject still manual `/refresh-memory`. |
| **injectscan** | H6-min fail-closed on memory/skill inject paths. |
| **Deps** | `charmbracelet/glamour`, `lrstanley/bubblezone` (+ existing Bubble Tea stack). Pure Go; no new list engine. |

## Install / 安装

**Recommended:**

```bash
brew install --cask yyZe0122/tap/ymz
# or upgrade: brew upgrade --cask ymz
ymz version && ymzd --check
```

```powershell
scoop bucket add ymz https://github.com/yyZe0122/scoop-bucket
scoop install ymz
# or: scoop update ymz
```

**Fallback:**

```powershell
$env:YMZ_VERSION = 'v0.2.4'
irm "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install.ps1" | iex
```

```bash
export YMZ_VERSION=v0.2.4
curl -fsSL "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install-user.sh" | sh
```

Config root: **`~/.yunmengze`** · `ymz paths user` · `ymz config validate --mode user`.

## Notes

- TUI: exit old process after upgrade (`/quit` then `ymz tui`) so the new binary loads.
- Streaming assistant text is plain by design; markdown styling applies after the turn completes.
- Job pin: create with empty `model_ref` stores current main; fire fails closed if pin cannot resolve.
- Affiliate repos: `yyZe0122/homebrew-tap` (`Casks/ymz.rb`), `yyZe0122/scoop-bucket`.
- Design status: `docs/optimization/current.md` · ADRs 018/043/044/045/040/042.
