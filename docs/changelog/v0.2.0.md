## Install / 安装

**Recommended:**

```bash
brew install --cask yyZe0122/tap/ymz
ymz version && ymzd --check
```

```powershell
scoop bucket add ymz https://github.com/yyZe0122/scoop-bucket
scoop install ymz
```

**Fallback:**

```powershell
$env:YMZ_VERSION = 'v0.2.0'
irm "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install.ps1" | iex
```

```bash
export YMZ_VERSION=v0.2.0
curl -fsSL "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install-user.sh" | sh
```

## Migration / 迁移

Alpha clean cut — no automatic migration:

1. Uninstall old binaries (`autozeagent` / `aze` / `autozeagentd`).
2. Copy config if needed: old `autozeagent.json` → `~/.config/yunmengze/agent.json` (or OS equivalent).
3. Install v0.2.0 via brew/scoop or one-liner above.
4. `ymz config validate --mode user` then `ymz`.
