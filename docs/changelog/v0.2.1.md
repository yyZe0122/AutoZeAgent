# YunmengZe Agent v0.2.1

**Alpha · Pre-release**

User config/data root is now a flat **`~/.yunmengze`** on all platforms
(Windows: `%USERPROFILE%\.yunmengze`). Override with `YMZ_HOME`.

用户态配置/数据根统一为 **`~/.yunmengze`**（Windows 为用户主目录下 `.yunmengze`）。

## Install

```bash
brew install --cask yyZe0122/tap/ymz
scoop bucket add ymz https://github.com/yyZe0122/scoop-bucket
scoop install ymz
# or update: scoop update ymz
export YMZ_VERSION=v0.2.1
curl -fsSL "https://raw.githubusercontent.com/yyZe0122/YunmengZe-Agent/main/packaging/scripts/install-user.sh" | sh
Config: ~/.yunmengze/agent.json · ymz paths user
